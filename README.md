## 📖 Visión General / Overview
**Huevo Chain** es una cadena de bloques soberana e independiente de Capa 1. No depende de Ethereum, Polygon, Solana ni de ninguna empresa centralizada. 

Combina la filosofía original de **Bitcoin** (emisión justa por Prueba de Trabajo / Proof of Work, 0 monedas pre-minadas) con la versatilidad de la **EVM de Ethereum** (soporte total para contratos inteligentes en Solidity, DeFi, NFTs y conexión nativa con MetaMask).

## ⛏️ Cómo Minar Huevo Chain / How to Mine

Cualquier persona puede minar **HV** utilizando su procesador (CPU) o tarjeta gráfica (GPU). Cada bloque resuelto premia al minero con **+2.0 HV** directamente en su billetera.

### 🪟 En Windows (1 Clic)
1. Descarga el paquete portátil: `HuevoChain-Minero-Portable.zip`.
2. Descomprime y ejecuta `INICIAR_MINERO.bat`.
3. Pega tu dirección de MetaMask (`0x...`) y presiona Enter. ¡Tu PC empezará a minar inmediatamente!

### 🐧 En Linux / macOS
```bash
# 1. Clonar el repositorio
git clone https://github.com/interpago/huevo-chain.git
cd huevo-chain

# 2. Iniciar minería (reemplaza con tu dirección pública)
bash mine.sh 0xTuDireccionPublicaDeMetaMask
```
